Descrição:
O Filmômetro é uma API REST para gerenciamento de avaliações de filmes. A plataforma permite que usuários cadastrem filmes, registrem suas opiniões (reviews), atribuam notas e consultem avaliações de outros usuários. O sistema também garante que cada usuário tenha acesso apenas aos seus próprios dados privados, como suas avaliações e histórico.

Usuários do sistema:

Usuários autenticados: podem cadastrar, editar e excluir suas próprias avaliações
Visitantes (não autenticados): podem visualizar filmes e avaliações públicas
Administrador (opcional): pode gerenciar conteúdos (ex: remover avaliações impróprias)
